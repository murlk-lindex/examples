公网「总仓」建仓步骤（只放 index.txt，一行一个 URL）
════════════════════════════════════════════════════════════════

钉死：
  · 总仓 ≠ 语言源码仓。语言源码不要推到总仓。
  · 总仓业务上只放一个文件：index.txt
  · 格式：一行一个 https URL（# 注释、空行忽略）
  · 每一行 = 某作者的库索引/入口（全网可 GET，不限 GitHub）
  · 用方默认只拉这一份 txt，再按行访问各家；不必为每个库改 mirror

建议命名：

  组织或用户：  murlk-lindex
  仓库名：      hub
  默认分支：    main
  可见性：      Public

公网文件地址（mum 内置）：

  https://raw.githubusercontent.com/murlk-lindex/hub/main/index.txt
  https://cdn.jsdelivr.net/gh/murlk-lindex/hub@main/index.txt
  （以及 Gitee / GitLab / ghproxy / murlk.dev 等同一份 txt）

────────────────────────────────────────────────────────────────
一、网页建仓
────────────────────────────────────────────────────────────────

1) New repository → 名：hub → Public → 空仓
2) 只提交一个文件：index.txt
   内容来自本机：stdlib/registry/index.txt
3) 浏览器打开 raw 地址应看到纯文本 URL 列表

────────────────────────────────────────────────────────────────
二、index.txt 长什么样
────────────────────────────────────────────────────────────────

  # 注释
  https://cdn.jsdelivr.net/gh/alice/cool-lib@main/index.json
  https://gitee.com/bob/lib/raw/master/index.json
  https://gitlab.com/carol/pkg/-/raw/main/index.json
  https://example.com/dave/murlk-pkgs/index.txt

  · 每行一个 URL
  · 目标可以是作者自己的 index.json，或再嵌套一份 index.txt
  · 必须全球可 GET 的 https

────────────────────────────────────────────────────────────────
三、用方
────────────────────────────────────────────────────────────────

  mum fetch
  mum search …
  mum install …

────────────────────────────────────────────────────────────────
四、别人如何登记
────────────────────────────────────────────────────────────────

  见 docs/guide/第三方独立库-自建仓发布.txt
  → 自建仓放包，向本总仓 index.txt 提 PR，追加一行自己的 URL

────────────────────────────────────────────────────────────────
五、本机编辑源
────────────────────────────────────────────────────────────────

  stdlib/registry/index.txt
  推送：只把该文件拷到总仓根目录名为 index.txt
