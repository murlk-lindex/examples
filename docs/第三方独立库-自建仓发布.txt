第三方独立库：自建仓 + 往总索引 index.txt 追加一行 URL
════════════════════════════════════════════════════════════════

总仓只发 index.txt（一行一个 URL）。语言源码不上总仓。
用方默认只拉这一份 txt。

────────────────────────────────────────────────────────────────
你要做的
────────────────────────────────────────────────────────────────

1) 自己任意主机放库（不限 GitHub）
   建议提供可 GET 的 index.json（含 packages）或再套一层 index.txt

2) 向总仓 murlk-lindex/hub 提 PR：只改 index.txt，末尾加一行你的 https URL

合入后：mum fetch 会读到你的行并去拉你的索引。

────────────────────────────────────────────────────────────────
作者侧 index.json 最小例（你自己仓里）
────────────────────────────────────────────────────────────────

  {
    "schema": "murlk-index/1",
    "packages": {
      "cool_lib": {
        "latest": "0.1.0",
        "versions": ["0.1.0"],
        "platforms": ["win-x64", "linux-x64"],
        "path": "packages/cool_lib/0.1.0",
        "home": "https://你的主机/项目页",
        "artifacts": {
          "win-x64": "https://你的主机/.../cool_lib.dll"
        }
      }
    }
  }

总仓 index.txt 里对应一行：

  https://你的主机/.../index.json

────────────────────────────────────────────────────────────────
用方
────────────────────────────────────────────────────────────────

  mum fetch
  mum search cool_lib
  mum install cool_lib

不必 mirror add 你的地址。

────────────────────────────────────────────────────────────────
本地自测
────────────────────────────────────────────────────────────────

  mum publish . → mum install <名>
