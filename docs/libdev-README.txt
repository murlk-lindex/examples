# 第三方独立库开发入口

标准库　　　　语言自带（stdlib/{eng,zh,bagua}）
第三方独立库　外部人员开发；登记进公网总索引

公网总仓：
  只发 index.txt（一行一个 https URL）
  不上语言源码；用方默认只认这一份

必读：
  教科书　　stdlib/libdev/教程-第三方独立库.txt
  自建仓登记　docs/guide/第三方独立库-自建仓发布.txt
  总仓建法　　docs/guide/GitHub总仓-建仓步骤.txt

配套：
  空骨架　　stdlib/libdev/TEMPLATE/
  本机样例　stdlib/registry/packages/hello_bin/0.1.0/
  总索引源　stdlib/registry/index.txt
  镜像表　　stdlib/registry/mirrors.mu
